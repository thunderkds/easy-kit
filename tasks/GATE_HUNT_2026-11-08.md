## P1-1 — a quoted `<<EOF` hides a real `git push --force` from the whole merge gate (every mode)

- Where: `.claude/hooks/lib/shell_data.py:108-157`. `HEREDOC_HEADER_PATTERN` ignores quotes and comments.
  The merge gate uses it at `pre_bash_block_unsafe_merge.py` (three call sites, near lines 995, 1444, 1759).
- Repro command (three lines): `echo "<<EOF"` / `git push --force origin main` / `EOF`.
- Result: ALLOWED with no tag, with `[auto]` and with `[admin]`. bash and zsh both really pushed.
- Same result for `echo '<<EOF'`, `true # <<EOF` and `echo \<<EOF`.
- Not a documented limit.
- Fix direction: do not strip a body whose `<<` sits inside quotes, after `#`, or after a backslash.
  When in doubt keep the text, so the gate sees more, never less.

## P1-2 — repo config and hooks the denylist misses run code during an `[admin]`-allowed merge or push

- Hooks missing from `ADMIN_HOOKS` (`pre_bash_block_unsafe_merge.py` near line 1306): `post-index-change`
  fires on every merge; `pre-auto-gc` fires on a non-fast-forward merge when auto gc triggers. Push fires
  only `pre-push` and `reference-transaction`.
- Config keys missing from `ADMIN_DENY_CONFIG` (near lines 1309, 1434). Each ran code, with the gate saying ALLOWED:
  - `merge.<d>.driver` together with `.git/info/attributes` (`* merge=<d>`), on `git merge`
  - `filter.<f>.smudge` (merge checkout) and `filter.<f>.clean` (via a chained `git status`)
  - `diff.<d>.textconv` (chained `git show HEAD`) and `diff.external` (chained `git diff HEAD`)
  - `gpg.program` with `commit.gpgsign` (the merge commit)
  - `core.editor` (via `git merge --edit`)
  - `credential.helper=/abs/prog` (only a leading `!` is refused): the helper ran at `git push` against a loopback 401 server
  - `http.proxy`: the push request went to the planted proxy
- Consequence: a merge driver defeats the `main` push check. `_main_push_refusal` compares the tree with
  `git merge-tree`, which uses the same driver. Repro: branch tip `f.txt` is `A\nb\nc`, `main` after the merge
  holds `UNVERIFIED CONTENT`, and `git push origin main` is ALLOWED.
- Not executed, ALLOWED by static check only: `filter.process`, `submodule.*.update=!cmd`, `core.askPass`.
- Not covered by the documented limits (they list only a hook or config added between the check and the push).
- Fix direction: replace the denylist with an allowlist of safe repo keys; refuse any executable hook;
  refuse `.gitattributes` / `info/attributes` lines with `merge=`, `filter=` or `diff=`; chained read-only
  git commands that run textconv or filters are not needed (`cd <dir> &&` only).

## P2-1 — the hidden-verb check misses cheap forms (ALLOWED, and the push really happens, `[auto]` and `[admin]`)

Forms that pushed: `v=push; git $v origin br`; `g=git; $g push ...`; `git ${v}sh ...`; `git {p..p}ush ...`;
`git $'push' ...`; `$'git' push ...`; `env -i git "push" ...`; `timeout 20 git "push" ...`;
`nice git "push" ...`; `bash -c 'git "push" ...'`; `git send-pack ../origin.git br`.
Blocked already: `command git "push"`, `git "push"`, `git pu\sh`.
Where: `OBFUSCATION` (near line 1314) knows only `${IFS}`, `$(`, a backtick and `eval`; `SHELL_WRAPPERS`
(near 1315) lacks `timeout`, `nice` and `env` with options; `hidden_git_verb` (near 1445) removes quoted spans first.

## P2-2 — `git merge --message feat/t900-x` fools the branch parser

`MERGE_OPTIONS_WITH_ARG` (near line 1096) lacks `--message`. The gate reads `feat/t900-x` as the branch and
checks its verify row; git takes it as the message and merges the upstream. Needs `merge.defaultToUpstream=true`
(not denied) plus an upstream ref. The later `main` push is still guarded.

## P2-3 — brace expansion and globs defeat `_escapes` in slot 2b

`task_context.py` near 443-456 and 536-538: the `{ }` and glob ban applies only to the `cd` target (near 399).
All of these were FILED under T120: `echo hi > {.,..}/f` (wrote outside the worktree in zsh);
`echo hi > {/abs/out,x}`; `git diff --output={.,..}/d` and `git log -1 --output={.,..}/d` (bash and zsh);
`pytest {..,.}/main/tests` (ran pytest on `../main/tests`); `pytest mt*` where `mtests` is a symlink to main.
Fix direction: refuse `{ }` in every token; resolve globs before the realpath check.
